# LEoPart-x

![](https://github.com/LEoPart-project/leopart-x/actions/workflows/ccpp.yml/badge.svg)
[![nightly](https://github.com/LEoPart-project/leopart-x/actions/workflows/nightly.yml/badge.svg)](https://github.com/LEoPart-project/leopart-x/actions/workflows/nightly.yml)

LEoPart-x (**L**agrangian-**E**ulerian **o**n **Part**icles-x) integrates
particle functionality into the open-source finite element library
[DOLFINx](https://github.com/FEniCS/dolfinx), a component of
[the FEniCS project](https://fenicsproject.org).

LEoPart-x is developed and tested against
[DOLFINx `v0.11.0`](https://github.com/FEniCS/dolfinx/releases/tag/v0.11.0).

## Documentation
A doxygen page can be generated by navigating to the `doc/` directory and typing

```bash
doxygen
```

## Dependencies

- [Python](https://www.python.org/) >= 3.11
- [DOLFINx](https://github.com/FEniCS/dolfinx) 0.11 (C++ library and Python
  interface)
- [Basix](https://github.com/FEniCS/basix)
- [nanobind](https://github.com/wjakob/nanobind) and
  [scikit-build-core](https://github.com/scikit-build/scikit-build-core)
  (build only)
- [ADIOS2](https://github.com/ornladios/ADIOS2) (optional, for
  `leopart.io`)

## Installation

LEoPart-x must be built with the same nanobind version as DOLFINx's Python
interface so that DOLFINx objects (meshes, functions, ...) can be passed to
LEoPart-x. Build without build isolation, against the nanobind and
scikit-build-core already installed alongside DOLFINx:

```bash
pip3 install --no-build-isolation .
```

#### Docker

Inside a `DOLFINx` Docker container

```bash
docker run -ti dolfinx/dolfinx:v0.11.0
git clone https://github.com/LEoPart-project/leopart-x.git
pip3 install --no-build-isolation ./leopart-x
```

#### Running the tests

```bash
cd test
python3 -m pytest .
mpirun -np 2 python3 -m pytest .
```
